# Solid Principles

| Letter | Principle                       | Simple meaning                                               |
| ------ | ------------------------------- | ------------------------------------------------------------ |
| **S**  | Single Responsibility Principle | One class should have **one responsibility**                 |
| **O**  | Open/Closed Principle           | Open for **extension**, closed for **modification**          |
| **L**  | Liskov Substitution Principle   | Child class should be usable wherever its parent is expected |
| **I**  | Interface Segregation Principle | Don't force a class to implement methods it doesn't need     |
| **D**  | Dependency Inversion Principle  | Depend on **abstractions**, not concrete classes             |
